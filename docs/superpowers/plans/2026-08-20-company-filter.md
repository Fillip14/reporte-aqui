# Company Filter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a problem's author optionally tag it with a responsible company (from the list of approved companies), and let the feed be filtered by that company.

**Architecture:** Extends the existing `problems` module with an optional FK (`responsibleCompanyId`) to `CompanyProfile`, adds a new public `companies` module for listing approved companies, and threads the selection/filter through the existing feed, create-problem, and problem-detail pages using the same React Query + Tailwind patterns already used there.

**Tech Stack:** Express + Prisma + PostgreSQL (backend); React + Vite + TypeScript + TanStack Query + Tailwind CSS (frontend); Vitest + Supertest (backend tests); Vitest + Testing Library + MSW (frontend tests).

**Spec:** `docs/superpowers/specs/2026-08-20-company-filter-design.md`

## Global Constraints

- `responsibleCompanyId` / "empresa responsável" is optional everywhere (schema, validation, forms) — never required.
- Only companies with `verificationStatus = 'approved'` may be selected as responsible, or accepted by the create-problem endpoint.
- `GET /companies` is public — no `requireAuth`/`optionalAuth` middleware, since the feed itself is browsable while logged out.
- Code identifiers (files, variables, routes) in English; user-facing text in Portuguese — existing project convention.
- Follow existing module patterns exactly: backend modules are `routes.ts` (thin) + `controller.ts` + `service.ts`; frontend API wrappers are thin functions in `api/*.ts`, consumed via TanStack Query in pages.

export async function listProblems(query: ListProblemsQuery, viewerId?: string) {
  const where: Prisma.ProblemWhereInput = {
    ...(query.status ? { status: query.status } : {}),
    ...(query.companyId ? { responsibleCompanyId: query.companyId } : {}),
    ...(query.q
      ? {
          OR: [
            { title: { contains: query.q, mode: 'insensitive' as const } },
            { description: { contains: query.q, mode: 'insensitive' as const } },
          ],
        }
      : {}),
  };

  const [problems, total] = await Promise.all([
    prisma.problem.findMany({
      where,
      include: {
        media: true,
        responsibleCompany: { select: { id: true, companyName: true } },
        _count: { select: { votes: true } },
      },
      orderBy: query.sort === 'top' ? { votes: { _count: 'desc' } } : { createdAt: 'desc' },
      skip: (query.page - 1) * query.limit,
      take: query.limit,
    }),
    prisma.problem.count({ where }),
  ]);

  const votedProblemIds = await votedIdsFor(viewerId, problems.map((p) => p.id));

  return {
    items: problems.map((p) => ({
      ...withMediaUrls(p),
      voteCount: p._count.votes,
      hasVoted: votedProblemIds.has(p.id),
    })),
    page: query.page,
    limit: query.limit,
    total,
  };
}

export async function createProblem(req: AuthenticatedRequest, res: Response) {
  const parsed = createProblemSchema.safeParse(req.body);
  if (!parsed.success) {
    return res.status(400).json({ error: 'invalid_input', details: parsed.error.flatten() });
  }

  try {
    const problem = await problemsService.createProblem(req.user!.id, parsed.data);
    return res.status(201).json(problem);
  } catch (err) {
    if (err instanceof ForbiddenObjectKeyError) return res.status(403).json({ error: 'forbidden_object_key' });
    if (err instanceof CompanyNotFoundError) return res.status(400).json({ error: 'company_not_found' });
    throw err;
  }
}
